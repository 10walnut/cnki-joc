# cnki-joc — 计算机学报（CJC）格式论文写作 Skill

[![WorkBuddy Skill](https://img.shields.io/badge/WorkBuddy-Skill-blue)](https://www.codebuddy.cn)

一个专为 [WorkBuddy](https://www.codebuddy.cn) / Claw 设计的 AI 技能包，用于按 **《计算机学报》（Chinese Journal of Computers）** 官方模板格式撰写和排版学术论文。

## 📦 安装

### 方式一：直接复制到本地

```bash
# 将整个文件夹复制到 WorkBuddy 用户技能目录
cp -r cnki-joc ~/.workbuddy/skills/
```

### 方式二：从 GitHub 克隆

```bash
git clone https://github.com/10walnut/cnki-joc.git ~/.workbuddy/skills/cnki-joc
```

安装后，在 WorkBuddy / Claw 中说出以下关键词即可自动触发：

> 「帮我写一篇计算机学报格式的论文」
> 「按 CJC 模板排版」
> 「投计算机学报的论文」
> 「计算机学报模板」

## ✨ 覆盖的排版规范

| 模块 | 内容 |
|---|---|
| **页面设置** | A4，正文双栏，标题/摘要区单栏 |
| **页眉（奇偶页不同）** | 首页：卷号/期号/学报名；奇数页：期号+作者+页码；偶数页：页码+学报+年份 |
| **首页页脚** | 收稿日期、基金资助、作者简介（含CCF会员号）、联系方式（投稿用） |
| **中文标题** | 2号黑体，居中 |
| **作者** | 3号仿宋_GB2312，居中 |
| **单位** | 6号宋体，居中 |
| **中文摘要** | 小5号宋体，5-7个关键词 |
| **英文 Title** | 4号 Times New Roman，加粗 |
| **英文 Abstract** | 5号 Times New Roman，约500词 |
| **一级标题** | 4号黑体 |
| **二级标题** | 5号黑体（如 1.1、1.2） |
| **三级标题** | 5号宋体（如 1.1.1） |
| **正文** | 5号宋体/TNR，首行缩进2字符 |
| **图表** | 图题/表题小5号，三线表，黑白矢量图 |
| **公式** | 居中，编号右对齐，变量斜体 |
| **参考文献** | 小5号，中英文对照，含各类格式示例 |
| **作者简介** | 小5号 Times New Roman |
| **英文 Background** | 小5号 Times New Roman，约400词 |

## 📄 论文结构建议

### 研究性论文
1. **引言** — 科学问题、意义、价值、贡献
2. **相关工作** — 独立成章，非引言子节
3. **方法/主要成果** — 含关键实现细节
4. **实验验证** — 环境设置、全面数据对比
5. **结论**

### 综述论文
1. **引言**
2. **问题与挑战**
3. **研究现状分析**（分析对比为主）
4. **未来研究方向**
5. **结论**

## ⚠️ 注意事项

- 摘要贡献部分需**数据支持**，避免模糊描述
- 关键词 5-7 个，中英文一一对应
- 首次出现缩写须写全称
- 定稿后作者署名和单位不能变更
- 长公式推导和大段数学论述放**附录**
