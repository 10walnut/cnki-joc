# 计算机学报参考文献格式指南

## 通用原则

- 参考文献按在正文中出现的顺序编号
- **中英文对照**排列：同一篇文献的中英文版本可并列（中文+英文对照），或先英文后中文
- 所有文献信息必须完整：作者、题目、出处、年、卷、期、页码
- 非正式出版物、内部资料、未公开的数据需标注清楚

## 各类型文献格式

### 1. 期刊论文 [J]

**格式**：
```
[序号] 作者. 题目[J]. 期刊名(全称), 年, 卷(期): 起止页码.
```

**示例**：
```
[3] Zhou Yong-Bin, Feng Deng-Guo. Design and analysis of cryptographic protocols for RFID. Chinese Journal of Computers, 2006, 29(4): 581-589 (in Chinese)
(周永彬, 冯登国. RFID安全协议的设计与分析. 计算机学报, 2006, 29(4): 581-589)
```

### 2. 会议论文 [C]

**格式**：
```
[序号] 作者. 论文题目[C]//Proceedings of the 会议名. 会议召开地点, 会议召开日期, 出版地: 页码.
```

### 3. 专著/书籍 [M]

**格式**：
```
[序号] 作者. 书名[M]. 版本(初版不写). 出版地: 出版社, 出版年份.
```

### 4. 学位论文 [D]

**格式**：
```
[序号] 作者. 论文题目[D]. 学位授予单位, 学位授予地点, 年份.
```

### 5. 技术报告 [R]

**格式**：
```
[序号] 作者. 报告题目[R]. 机构地点: 机构, 报告年份.
```

### 6. 专利 [P]

**格式**：
```
[序号] 专利拥有者. 专利名称: 专利国别, 专利号[P]. 公告日期.
```

### 7. 在线资源/网络文献

**格式**：
```
[序号] 作者. 题目[EB/OL]. (发布日期). 网址.
```

### 8. 论文集/标准/汇编 [S]

**格式**：
```
[序号] 作者. 题目[S]//编者. 论文集名. 出版地: 出版社, 出版年: 页码.
```

## 作者规则

- 多个作者间用逗号分隔
- 英文作者：名首字母大写 + 姓全称，如 Yong-Bin Zhou → Zhou Yong-Bin
- 中文作者：直接写全名，如 周永彬
- 超过 3 个作者时，前 3 个列出后加 "等" 或 "et al."

## 正文引用标记

- 正文引用使用上标方括号编号：如 **[1]**、**[2-4]**、**[5, 6]**
- 编号与参考文献列表的序号严格对应
